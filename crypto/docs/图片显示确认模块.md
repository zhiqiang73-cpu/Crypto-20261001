# 图片显示确认模块

面板左侧导航第 **03** 项。把 bot 真正使用的那条行情序列画出来，并标出策略的 B / S 信号，
用于人工核对「策略有没有按规则执行」。**只读展示，不含任何下单动作。**

---

## 1. 能看什么

| 区域 | 内容 |
| --- | --- |
| 主图 | BTCUSDT / ETHUSDT 永续 K 线（15m / 5m），最新价横线，推演持仓底纹 |
| B / S 标记 | B = 金叉且 MACD 柱为正；S = 死叉且 MACD 柱为负。实心＝会执行（开仓/反手），空心＝重复信号（已持仓、不动作） |
| 成交标记 | 运行器落盘的实际策略成交（`deployed_trades.csv`，非「观察」行），圆点按方向着色 |
| KDJ 副图 | K 线（蓝）、D 线（橙）、J 线（灰虚线）、20/50/80 参考线；J 不参与决策 |
| MACD 副图 | 能量柱（柱 > 0 绿、柱 < 0 红）+ DIF / DEA 双线 + 零轴 |
| 缩放 / 平移 | 滚轮放大缩小（以光标下的那根 K 线为锚点）、按住拖动平移、双击或「复位视图」回到全窗口 |
| 十字线 | 悬停时画出竖直虚线，只标位置，不弹任何浮层 |
| 信号明细表 | 窗口内每一条 B/S：时间、信号、动作、K、D、MACD 柱、判定依据 |
| 头部比对行 | **运行器同根读数**（K/D/柱）+ 逐项一致性 ✅/⚠️ + 运行器持仓 + 快照时间 |

控制项：标的（BTCUSDT / ETHUSDT）、周期（15m / 5m）、显示根数（120 / 200 / 300 / 500）、
显示 B/S、显示成交、自动刷新（5 秒）、立即刷新、复位视图。快捷键 `R` 在任一页都可用。

缩放范围：最少 20 根，最多＝取到的全部根数；K 线 / KDJ / MACD 三栏同步，纵轴按**可见区间**
重算（放大后价格刻度自动变细）。切换标的或周期时视图复位到全窗口；自动刷新换新 K 线时
保持当前缩放与位置（`offset` 从右端计数，新 K 线到来即自然跟随最新一根）。

## 2. 口径（与运行器同源，不另立一套）

* **行情地址**由 `config/market_endpoints.resolve_for_account()` 从**账户地址反推**：
  账户在测试网 → K 线就是测试网。这是 2026-10-02 市场错位事故的硬闸门。
  页面上直接显示当前市场与 K 线 URL 供核对。
* **KDJ(9,3,3) / MACD(12,26,9)** 直接加载 `shadow/indicators.py` 的**同一份函数**
  （按文件路径加载，绕开 `shadow` 包的 `__init__`，避免把线上运行器带进面板进程）。
* **交叉与闸门**直接加载 `shadow/signals.py`：金叉且柱正 → B；死叉且柱负 → S；
  方向背离的交叉一律丢弃（不开仓、不平仓、不反手）。
* **执行口径**：信号在当根收盘判定，**下一根 K 线开盘执行**；标记画在信号 K 线上。
* **单仓不加仓**（`max_concurrent = 1`）：已持多时再出同向 B 只画空心标记、不动作；
  只有对侧有效信号才反手。底纹＝按该规则推演出的理论持仓方向。
* **指标预热 500 根**，默认展示最近 200 根。KDJ/MACD 的递归初值影响按 2/3、0.846 的
  幂次衰减，500 根远多于收敛所需，因此与运行器的短窗口读数一致（见下）。

## 3. 接口

```
GET /api/chart?symbol=BTCUSDT|ETHUSDT&interval=15m|5m&bars=50..500
```

返回：`bars[]`（含 o/h/l/c/v/k/d/j/dif/dea/hist/pos）、`signals[]`（side/kind/action/reason）、
`trades[]`、`latest`、`runner`（运行器同根读数）、`parity`（逐项比对）、
`market` / `kline_url` / `params` / `signal_rule`。

服务端带 3 秒缓存，避免面板高频刷新时压测行情接口。

## 6. 已知边界

* 5m 策略在 `config/strategies/` 中标记为 `disabled_2026-10-03`，但本页**仍会画出 5m 的
  K 线与信号**（属于「按同一规则推演」），用于对照，不代表 5m 正在实盘运行。
* 「推演方向」是从抓取窗口起点按信号规则推演的理论持仓；**运行器持仓**是实际账本。
  两者不一致是正常且值得注意的（例如记录起点清零后运行器为空仓，而理论方向仍为多）。
* 成交标记依赖 `runtime/shadow/deployed_trades.csv`。该文件在 2026-10-03 18:42 按用户
  要求清零，因此当前窗口内没有成交标记；随实盘成交会自然出现。
* 本模块不写任何文件、不下单、不参与评分；除面板进程外不触碰任何线上运行器。
